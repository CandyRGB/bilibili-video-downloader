# B站视频下载器（Edge / Chrome 扩展）

在 B 站播放器里直接下载视频：支持 1080P+/4K 高清、音视频自动合并成单文件、分P 批量、仅下音频。

---

## 安装

1. 打开 `edge://extensions/`（Chrome 是 `chrome://extensions/`）
2. 打开左下角「开发人员模式」
3. 点「加载解压缩的扩展」，选择本目录（`bilibili-downloader`）
4. 打开任意 `bilibili.com/video/...` 页面，播放器右侧会出现一个下载标签

> 需要 Chromium 111+（用到了 `world: MAIN` 之外的基础能力，实际 Edge 100+ 都可用）。

## 使用

点右侧的下载标签 → 选择画质 / 编码 / 下载内容 → 点「开始下载」。

- **音视频合并**（默认）：B 站高清是音视频分离的两条流，插件下载后自动合并成一个 `.mp4`。画质最高。
- **单文件**：B 站直出的 MP4，无需合并，可直接播放，但画质上限通常只有 720P。
- **仅音频**：只下音频轨，存为 `.m4a`。

分P / 分集视频会在面板顶部列出全部，可勾选多个批量下载（多选时会让你选一个输出文件夹）。

第一次点「开始下载」会弹出系统的「另存为」对话框，选定后就是**边下边写**，不会先占满内存。

## 画质与编码

| 编码 | 说明 |
|---|---|
| **AVC / H.264** | 默认。兼容性最好，任何播放器都能放 |
| AV1 | 体积最小，Chrome / Edge 原生支持解码 |
| HEVC / H.265 | 体积小，但 Windows 需装「HEVC 视频扩展」才能播，不确定就别选 |

能拿到什么画质取决于你的账号：未登录通常 480P 封顶，登录后 1080P，大会员才有 1080P+ / 4K / HDR。

## 工作原理

| 环节 | 做法 |
|---|---|
| 取流 | 调 `x/player/playurl`（带页面 Cookie）拿 DASH 清单，视频流与音频流各有独立地址 |
| 防盗链 | CDN 只校验 `Referer`，浏览器从 B 站页面发起的请求会自动带上，因此无需伪造 |
| 跨域 | CDN 返回 `Access-Control-Allow-Origin: *`，所以请求必须用 `credentials: 'omit'`（带凭证的跨域请求不接受通配符源） |
| 合并 | 不解码、不重编码，只在分片级搬运 `moof/mdat`：重建 `moov`（视频 trak + 音频 trak + 两个 `trex`），按 `tfdt` 时间戳交错输出，丢弃已失效的 `sidx` |
| 落盘 | 优先 File System Access API 流式写盘（内存恒定）；不支持时退回 Blob 下载 |
| 容错 | 主地址失败时自动切 `backupUrl` 备选节点；响应头 15s 超时、数据流 20s 断流检测，避免卡死 |

合并器是纯 JavaScript 实现（`lib/fmp4-mux.js`），无第三方依赖，全程流式，内存占用与文件大小无关。

## 已知限制

- 下载过程中请**保持页面在前台**，浏览器会节流后台标签页的网络请求。
- 付费 / 充电专属 / 地区限制内容，插件只跟随你账号本来的权限，不会绕过。
- 输出是分片式（fragmented）MP4，Edge / Chrome / VLC / ffmpeg 都能正常处理；个别老旧播放器或剪辑软件可能需要先用 `ffmpeg -i in.mp4 -c copy out.mp4` 转成普通 MP4。
- 不支持直播流、弹幕、字幕轨道。

## 排查

在视频页按 F12，控制台输入：

```js
__bdTrace
```

会打印取流与重试过程（哪个 CDN 节点失败、是否触发了换源）。汇报问题时带上这段信息即可。

常见提示：

- **Failed to fetch / 连接超时** → 网络中断或 CDN 节点不可用，插件会自动换源重试；反复出现就换个时间再试。
- **接口错误 -403 / 87007** → 该视频需要大会员或充电才能观看。
- **没有可用的视频流** → 该视频是音频投稿或结构特殊，试试「单文件」模式。

```
bilibili-downloader/
├── manifest.json          # MV3 清单
├── popup.html / popup.js  # 工具栏弹窗（编码偏好、打开面板）
├── content/
│   ├── content.js         # 面板 UI + 取流 + 下载/合并/重试
│   └── content.css
├── lib/
│   └── fmp4-mux.js        # 分片级 fMP4 合并器
├── icons/                 # 图标
└── tools/make_icons.py    # 图标生成脚本（不参与运行）
```
